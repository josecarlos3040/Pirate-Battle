# Pirate Battle

Pirate Battle is a small naval combat game developed as part of a Game Developer Challenge.

The project combines a React interface with a PixiJS real-time game, including configurable matches, enemy AI, shooting mechanics, local persistence, mocked REST APIs, ranking, match history, mobile controls, and automated E2E tests.

## Tech Stack

- React
- TypeScript
- Vite
- PixiJS
- Axios
- TanStack Query
- MSW
- Playwright

## Requirements

- Node.js
- npm
